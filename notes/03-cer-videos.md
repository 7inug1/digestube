# CER 측정용 정답 영상 선정

상태: 진행 중

> **TLDR**: 자막이 있다고 다 정답으로 쓸 수 있는 건 아니다. 채널 6곳, 영상 13편을 직접 확인한 결과 "자동 생성"과 "사람이 올린 자막"을 yt-dlp로 구분해야 했고, 브랜드 명성만으로는 판단이 자주 틀렸다(세바시도 절반은 없었다). 마지막 단계(사람이 직접 내용 대조)만 아직 안 했다.

STT 정확도(CER)를 재려면 "사람이 정확하게 옮긴 자막이 있는 영상"이 필요하다. 이걸 어떻게 찾고 검증하는지 정리한다.

## 3단계 검증 절차

1. **후보 채널 자격** — 자막 제작 의무나 관행이 있는 곳(방송사, 공식 기관, 강연 플랫폼)을 후보로 삼는다. 이건 1차 필터일 뿐, 통과를 보장하지 않는다.
2. **영상 단위 자동 검증** — `yt-dlp --list-subs`로 확인한다. "Available automatic captions"(자동 생성)와 "Available subtitles"(사람이 올린 것)가 구분되어 나온다. 후자에 그 영상이 있어야 한다. 화면에 자막이 박혀 있는 영상(글자가 보여도 텍스트로 추출은 안 됨)은 여기서 걸러진다.
3. **사람이 직접 보고 대조** — 2단계는 "사람이 올렸다"만 확인해준다. 내용이 실제로 정확한지는 못 봐준다. 사람이 올린 자막도 원문을 그대로 옮긴 게 아니라 편집한 버전일 수 있다(군더더기 제거 등). 이 단계는 자동화가 안 되고 사람이 직접 봐야 한다. 아직 실행 안 함.

## 실제 확인 결과

| 채널 | 확인 영상 | 결과 |
|---|---|---|
| 서울대학교 공식 | 컴공 1편 | 있음 (기존 사용 중) |
| EBS 자막뉴스 재생목록 | 1편 | 없음 (화면에 박힌 자막) |
| 세바시 | 4편 | 2편만 있음 |
| TEDxSeoul | 1편 | 없음 |
| TED 공식(영어) | 3편 | 1편만, 그나마 아랍어 |
| PBS NewsHour(영어) | 3편 | 3편 다 있음 |

## 패턴

브랜드·기관 명성만 보고 판단하면 틀린다. 같은 채널 안에서도 영상마다 자막 유무가 갈린다(세바시 50%). 매번 영상 단위로 직접 확인하는 것 외엔 지름길이 없다.

## 스코프 관련

파이프라인 자체는 다국어를 지원하는데(Whisper `language=None` 자동 감지, e5 다국어 임베딩) 검증은 한국어 하나뿐이다. PBS NewsHour가 영어 후보로 확인됐다. 이 확장은 나중으로 미룬다.
