# yt-dlp (오디오 추출)

상태: 완료

## 결론

유튜브 공식 API(Data API v3)는 오디오·영상 스트림 다운로드 기능 자체가 없다. 그래서 애초에 비교 대상이 아니었다. 남은 오픈소스 후보(youtube-dl, pytube)는 실제로 확인해보니 둘 다 유지보수가 사실상 멈춰있어 실질적 대안이 못 됐다.

## 근거

| 도구 | 상태 |
|---|---|
| yt-dlp | 2주마다 릴리스, PyPI 월 1,200만 다운로드 |
| youtube-dl | 안정 릴리스가 2021년 12월이 마지막 (4년 넘게 정지) |
| pytube | 2026년까지도 추출 실패 이슈가 계속 열려있음, 커뮤니티가 pytubefix로 이탈하는 중 |

## 핵심 확인

유튜브는 2024년부터 PO Token을 요구하기 시작하면서 봇 차단을 강화했다. yt-dlp의 android 클라이언트 우회 옵션(`--extractor-args "youtube:player_client=android"`)은 이 2024년 변화 이후에 추가된 기능이다. 4년 전에 멈춘 youtube-dl에는 애초에 이 옵션이 존재할 수 없었다.

"유지보수가 빠른 도구가 낫다"가 아니라, "2024년에 새로 생긴 문제를 그 이후로도 계속 패치되고 있는 도구만 풀 수 있었다"가 정확한 설명이다.
