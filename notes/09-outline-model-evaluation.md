# 목차 생성 모델 평가 설계

상태: 실행 준비. 기존 Haiku를 임시 기준선으로 두고, 모델 자체는 아직 고르지 않는다.

## 목적

문단 하나에서 아래 JSON을 안정적으로 만든다.

```json
{"label":"목차 제목","quote":"원문에 실제로 있는 근거 문장"}
```

## 1차 자동 탈락

- JSON 파싱 불가
- `label`이 비었거나 25자를 넘김
- `quote`가 문단 원문에 없음(공백·구두점 무시 부분 일치)
- 호출 오류

## 2차 사람 채점 (8점)

각 항목을 0·1·2점으로 매긴다.

| 항목 | 2점 기준 |
|---|---|
| 핵심 일치 | 문단의 중심 내용을 정확히 표현 |
| 구체성 | 제목만 보고 다루는 내용을 알 수 있음 |
| 탐색성 | 사용자가 원하는 구간인지 판단할 수 있음 |
| 비중복성 | 같은 영상의 앞뒤 제목과 역할이 겹치지 않음 |

항목별 7점 이상이면서 `핵심 일치`가 2점이어야 통과다. 전체 영상의 중복 제목 비율도 10% 이하로 본다.

## 후보와 실행 순서

1. Claude Haiku 4.5 — 현재 기준선
2. GPT-5 mini
3. Gemini 3.5 Flash-Lite
4. HyperCLOVA X HCX-007
5. Mistral Small 4

`web/scripts/benchmark_outline.py`는 기존 v1의 13개 영상에서 앞·중간·뒤 문단을 고르게 뽑는다. 서비스 DB와 현재 목차는 수정하지 않고 `web/data/evals/`에 모델별 결과를 저장한다.

첫 라운드는 영상당 1문단(13개)으로 API 연동과 자동 통과율을 확인한다. 통과한 모델만 영상당 3문단(최대 39개)으로 확대하고 사람 채점을 한다.
