# Digestube

유튜브 영상을 목차와 전사문으로 읽고, 자연어 질문으로 관련 대목을 찾는 영상 탐색 서비스.

[서비스 보기](https://digestube.vercel.app) · [검색](https://digestube.vercel.app/search)

## 주요 기능

- **전사:** Gemini API에 유튜브 URL을 전달해 발화별 텍스트와 시각을 수집합니다.
- **주제별 문단:** 모델이 발화 번호로 경계를 선택하고 코드가 원문을 보존해 문단을 구성합니다. 실패 시 문장 경계 기반 분할로 전환합니다.
- **목차:** 전사문 전체에서 주요 내용을 묶고, 제목 길이와 근거 인용문의 원문 포함 여부를 검사합니다.
- **의미 검색:** KURE-v1과 pgvector로 상위 3개 문단을 찾습니다. 같은 영상의 결과는 묶고, 문단 전문·관련 문장 강조·타임스탬프를 제공합니다.
- **이어 읽기:** 목차와 문단에서 영상 재생 위치로 이동합니다. 재생 실패 안내, 재등록 확인, 목차·임베딩 처리 재개를 지원합니다.

## 기술 구성

TypeScript · Next.js · Gemini API · KURE-v1 · PostgreSQL/pgvector · Supabase · Vercel

`유튜브 URL → Gemini 전사 → 주제 청킹 → 목차·임베딩 → 읽기·검색`

앱과 API는 [web/](web/), 실험·판단 기록은 [notes/](notes/)에 있습니다. Supadata는 플레이리스트 조회와 전사 대체 경로에 남아 있습니다.

## 로컬 실행

Node.js 22 이상을 권장합니다.

```sh
cd web
npm ci
cp .env.local.example .env.local
npm run dev
```

환경변수와 DB 준비 방법은 [웹 실행 안내](web/README.md)를 참고하세요.

## 현재 범위

강연·인터뷰·설명 등 발화 중심 영상에 맞춘 서비스입니다. 검색 결과를 보여주며 별도 답변 생성은 제공하지 않습니다. 전사·목차의 의미 정확성과 주제 청킹 모델의 최종 비교 평가는 진행 중입니다. 검색 커트라인은 아직 적용하지 않아 무관한 질문에도 결과가 나올 수 있습니다.

이전 전사·청킹으로 측정한 검색 수치는 현재 코퍼스의 성능 보증이 아닙니다. 실험 조건과 한계는 각 노트에 기록합니다.
