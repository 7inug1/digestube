# 검색 질문 검토표

**아직 정답지가 아니다.** 질문과 정답을 사용자가 확인한 뒤 버전을 고정한다. 검색 결과를 먼저 보고 정답 구간을 정하지 않는다.

## 먼저 할 일

익숙한 영상 하나를 골라, 내용을 찾을 때 실제로 할 법한 질문부터 만든다. 처음에는 소수 문항으로 검토 방법을 익히고, 검색 실행 전 여러 영상으로 범위를 넓힌다. 답이 없는 질문도 전체 코퍼스를 확인한 뒤 추가한다.

## 작성 양식

문항마다 아래 항목을 복사해서 채운다. 모르는 항목은 빈칸으로 두며 추측해서 정답 처리하지 않는다.

- 문항 ID:
- 질문:
- 유형: 답 있음 / 답 없음
- 작성자: 사용자 / AI 초안
- 용도: 개발용 / 최종 확인용
- 정답 영상 ID·제목: 답 없으면 해당 없음
- 정답 시간 구간: 시작 초 ~ 끝 초, 복수 가능
- 정답 근거: 실제 내용과 해당 구간을 골랐던 이유
- 답 없음 확인: 답 없는 질문일 때 전체 코퍼스 검토 근거
- 사용자 검토: 미검토 / 수정 필요 / 확인 완료
- 검토 메모:

## 확정 현황

- 질문: 0개
- 사용자 확인 완료: 0개
- 질문 버전: 초안, 미고정
- 검색 실행: 하지 않음

현재 문항이 없는 이유: AI가 만든 질문을 사용자 확인 없이 정답지로 확정하지 않기 위해서다.
