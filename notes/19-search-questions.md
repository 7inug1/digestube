# 검색 질문 검토표 — AI 초안 25개

**답 있음 20개 · 답 없음 5개. 검색 결과·점수는 아직 보지 않았다.**

전체 8편의 저장 전사문을 읽고 작성했다. 영상 원음을 직접 듣고 검수한 정답지가 아니다. 아래 질문·요약·시각은 모두 사용자 검수 전이다. 검색 성공률은 아직 없다.

## 검수하는 법

각 질문을 보고 **괜찮음 / 질문 수정 / 정답 수정 / 제외** 중 하나를 알려주면 된다. 수정할 번호만 모아서 전달해도 된다. 링크는 원본 영상의 해당 자막 시작 위치로 이동한다.

- 원문 표현을 그대로 묻는 질문만 되지 않도록 일상적인 표현과 구체적인 정보 질문을 섞었다.
- 모든 질문은 한국어다. 영어 전사 영상 2편에 대한 한국어 검색도 포함한다.
- 개발용 17개(답 있음 14·없음 3), 최종 확인용 8개(답 있음 6·없음 2)를 실행 전에 구분했다. 최종 확인용 점수는 튜닝 중 열어보지 않는다. 표본이 작아 서비스 전체 성능으로 일반화하지 않는다.
- 시각은 문단 경계가 아니라 근거 구절에 대응하는 원본 자막 조각으로 잡았다. 겹치는 시간만으로 의미 정확성을 보장하지 않는다.
- 이 초안은 대표적인 근거 구간을 제시한다. 같은 답이 다른 구간에도 있으면 검수 때 추가하고, 추가 검토 전에는 완전한 정답 구간 목록이라고 보지 않는다.
- 기존 질문 11개로 임계치를 살펴본 이력이 있으므로 완전히 새로운 코퍼스 검증은 아니다. 이번에는 그 질문 목록을 그대로 재사용하거나 검색 점수에 맞춰 고르지 않았다.
