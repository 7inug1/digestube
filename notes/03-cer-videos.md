# CER 측정용 정답 영상 선정

상태: 진행 중

> **TLDR**: 자막이 있다고 다 정답으로 쓸 수 있는 건 아니다. 채널 6곳, 영상 13편을 직접 확인한 결과 "자동 생성"과 "사람이 올린 자막"을 yt-dlp로 구분해야 했고, 브랜드 명성만으로는 판단이 자주 틀렸다(세바시도 절반은 없었다). 마지막 단계(사람이 직접 내용 대조)만 아직 안 했다.

STT 정확도(CER)를 재려면 "사람이 정확하게 옮긴 자막이 있는 영상"이 필요하다. 이걸 어떻게 찾고 검증하는지 정리한다.

## 3단계 검증 절차

1. **후보 채널 자격** — 자막 제작 의무나 관행이 있는 곳(방송사, 공식 기관, 강연 플랫폼)을 후보로 삼는다. 이건 1차 필터일 뿐, 통과를 보장하지 않는다.
2. **영상 단위 자동 검증** — `yt-dlp --list-subs`로 확인한다. "Available automatic captions"(자동 생성)와 "Available subtitles"(사람이 올린 것)가 구분되어 나온다. 후자에 그 영상이 있어야 한다. 화면에 자막이 박혀 있는 영상(글자가 보여도 텍스트로 추출은 안 됨)은 여기서 걸러진다.
3. **사람이 직접 보고 대조** — 2단계는 "사람이 올렸다"만 확인해준다. 내용이 실제로 정확한지는 못 봐준다. 사람이 올린 자막도 원문을 그대로 옮긴 게 아니라 편집한 버전일 수 있다(군더더기 제거 등). 이 단계는 자동화가 안 되고 사람이 직접 봐야 한다. 아직 실행 안 함.

## 실제 확인 결과

| 채널 | 확인 영상 | 결과 |
|---|---|---|
| 서울대학교 공식 | 컴공 1편 | 있음 (기존 사용 중) |
| EBS 자막뉴스 재생목록 | 1편 | 없음 (화면에 박힌 자막) |
| 세바시 | 4편 | 2편만 있음 |
| TEDxSeoul | 1편 | 없음 |
| TED 공식(영어) | 3편 | 1편만, 그나마 아랍어 |
| PBS NewsHour(영어) | 3편 | 3편 다 있음 |

## 왜 세바시·PBS NewsHour인가

**세바시** — 강연 콘텐츠라 말이 또박또박하고 화자가 한 명이다. 스튜디오 녹음이라 잡음도 적다. 받아쓰기 정답을 만들기에 조건이 좋고, 무엇보다 우리가 다루려는 콘텐츠(유튜브 강연·자기계발 영상)와 성격이 같다. 정답 영상은 우리가 실제로 처리할 콘텐츠와 비슷해야 의미가 있다.

**PBS NewsHour** — 미국 공영방송이다. 미국은 FCC(연방통신위원회)가 방송사에 폐쇄자막 제공을 의무화하고 있어서, 자막을 정식 절차로 만든다. 한국의 방송법 제69조 8항이 KBS·EBS 등에 같은 의무를 지우는 것과 같은 구조다. 개인이 취미로 단 자막과 달리 제작 공정이 있다는 뜻이라 신뢰도가 높다.

## 세바시의 구조적 결함 (2단계에서는 안 걸림)

세바시 "에디토리얼" 시리즈는 영상 맨 앞에 나중 내용을 미리 보여주는 티저 구간이 있는데, **거기에는 자막을 달지 않는다.** 영상 두 편을 확인했더니 둘 다 같은 패턴이었다.

| 영상 | 자막 범위 | 비어있는 구간 |
|---|---|---|
| 세바시 ep.3 (fGNGKCz60NE, 821초) | 30.4초 ~ 800초 | 앞 30초 |
| 세바시 ep.2 (hizcp09ch0o, 867초) | 34.9초 ~ 844초 | 앞 35초, 뒤 23초 |
| PBS (EzG8dcpdMH4, 150초) | 0.4초 ~ 149.3초 | 거의 없음 |

티저 구간에도 실제 말소리는 있다. 그래서 STT는 제대로 받아쓰는데 정답지에는 그 부분이 없어서, 맞게 받아쓴 걸 틀렸다고 채점하게 된다. 실제로 fGNGKCz60NE로 mlx-whisper를 재봤더니 전체 기준 CER 4.14%였는데, 앞 30초를 빼고 재면 0.94%였다. **"오류"의 77%가 STT 잘못이 아니라 정답지 결함이었다.**

세바시를 쓰려면 자막이 시작되는 시점 이후만 채점 범위로 잡아야 한다. 영상을 바꿔도 같은 문제가 나오므로 영상 선택으로는 해결되지 않는다.

## 3단계 검수용 스크립트

사람이 영상을 보면서 자막 내용이 맞는지 대조할 수 있도록 "시각 + 문장" 형태로 폈다. 생성 스크립트는 `server/make_script.py`.

| 파일 | 대상 | 분량 |
|---|---|---|
| `server/work/script_PBS.txt` | PBS 2분 30초 | 34줄 |
| `server/work/script_세바시.txt` | 세바시 13분 41초 | 84줄 |

## 패턴

브랜드·기관 명성만 보고 판단하면 틀린다. 같은 채널 안에서도 영상마다 자막 유무가 갈린다(세바시 50%). 매번 영상 단위로 직접 확인하는 것 외엔 지름길이 없다.

## 스코프 관련

파이프라인 자체는 다국어를 지원하는데(Whisper `language=None` 자동 감지, e5 다국어 임베딩) 검증은 한국어 하나뿐이다. PBS NewsHour가 영어 후보로 확인됐다. 이 확장은 나중으로 미룬다.

## 남은 일

- **3단계 검수**: 위 스크립트 두 개를 영상과 대조해서 "자막이 실제 말과 맞는가" 확인. 사람이 해야 하는 단계다.
- 검수 통과한 것만 정답 영상으로 확정(장르 다양하게 2~3편)
- 확정된 영상으로 `02-stt.md`의 후보 CER 재측정

`02-stt.md`에 이미 적힌 측정값 3개(mlx-whisper 4.14%·Groq 4.21%·유튜브자막 6.34%)는 이 3단계를 건너뛰고 잰 값이라 무효다. 검수 후 다시 잰다.
