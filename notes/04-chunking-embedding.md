# 청킹용 임베딩 모델

상태: 진행 중 — 1단계 완료

## 왜 다시 보나

기존에 쓰던 multilingual-e5-small은 원래 검색(retrieval) 용도로 설계된 모델이다. 청킹이 실제로 하는 일은 문장 간 유사도(STS, Semantic Textual Similarity) 측정이다. 서로 다른 과제다. 검색을 잘하는 모델이 STS도 잘한다는 보장은 없다.

## 후보 (카테고리별로 채움)

| 구분 | 모델 | 만든 곳 |
|---|---|---|
| 해외 빅테크 | multilingual-e5-small/large | Microsoft |
| 해외 빅테크 | OpenAI text-embedding-3-small | OpenAI |
| 해외 빅테크 | Cohere Embed v3 | Cohere |
| 해외 연구기관 | BGE-M3 | BAAI(중국) |
| 국내 학계 | KoE5 | 고려대 nlpai-lab |
| 국내 기업 | Solar Embedding-1-Large | 업스테이지 |
| 개인/커뮤니티 | KoSimCSE | 미확인 |

네이버 자체 독립 임베딩 모델은 찾지 못했다. "없음"으로 남긴다.

처음 검색했을 때는 국내 기업 카테고리가 빠져 있었다. 카테고리를 먼저 정하고 각각 채우는 방식으로 다시 조사해서 업스테이지를 찾았다.

## 제외 기준 (정함, 아직 미적용)

1. 접근 자체 불가 (승인 필요, 상업적 이용 금지 라이선스)
2. 문장 임베딩 미지원
3. 서비스 종료

8개 다 접근 가능해 보여 제외 대상이 없을 가능성이 높다. BGE-M3(중국 BAAI)의 상업적 이용 라이선스만 확인이 필요하다.

## 남은 일

1. BGE-M3 상업적 이용 라이선스 확인
2. KorSTS·KLUE-STS 벤치마크에서 이 7~8개 모델 점수 찾기 (STT 때 rtzr 벤치마크 같은 역할을 할 자료)
3. 기준(STS 성능·속도·크기) 가중치를 AHP로 도출
4. 점수표 완성 후 최종은 우리 콘텐츠로 직접 검증
