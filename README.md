# Digestube v2

기존 [digestube](../digestube) 프로젝트를 다시 만드는 저장소입니다. 이번엔 기술 하나를 고를 때마다 후보 나열부터 근거까지 `notes/`에 먼저 남기고, 그 근거로 코드를 짭니다.

`notes/`는 작업 중 판단 과정을 기록하는 곳입니다. 서비스가 완성되면 이 폴더는 지우고, 최종 판단만 정식 문서(`docs/decision-log.md` 등)로 옮깁니다.

## 진행 순서

1. [x] STT(음성 전사) — 진행 중, `notes/02-stt.md`
2. [ ] 청킹용 임베딩 모델 — 진행 중, `notes/03-chunking-embedding.md`
3. [ ] 목차 생성 모델(Claude Haiku 등)
4. [ ] 저장소(SQLite vs 벡터DB)
5. [ ] 나머지 파이프라인

## 방법론

기술 하나를 고를 때마다 이 순서를 따릅니다. 자세한 설명은 `notes/00-methodology.md` 참고.

1. 후보 나열 — 카테고리(해외 빅테크·해외 연구기관·국내 기업·국내 학계·개인) 먼저 정하고 각각 채운다
2. 명백히 못 쓰는 것 제거
3. 판단 기준 정하기
4. 기준마다 가중치 — AHP(쌍대비교)로 도출한다
5. 후보마다 기준별 점수 매기기 — 공식으로, 느낌으로 찍지 않는다
6. 가중치 곱해서 합산 순위
7. 결론 — 남의 벤치마크는 참고만, 최종 판단은 우리 콘텐츠로 직접 측정한 결과로 남긴다
